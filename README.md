## ⚡ About Me

I'm an Artificial Intelligence and Machine Learning graduate student at **Technische Universität Darmstadt** with a background in Computer Science and Engineering. My work sits at the intersection of generative AI, scalable data engineering, and production software development. 

Before starting my Master's in Germany, I developed enterprise C# and C++ components with Angular interfaces as a Software Developer Apprentice at **Siemens**, and engineered high-throughput Python and SQL data pipelines as a Data Engineer Intern at **Increff**. Today, I design multi-agent workflows, retrieval-augmented generation systems, and deep learning architectures for computer vision and predictive modelling.

---

## 🎯 Personal Mission Statement

> **To turn complex machine learning research into reliable, explainable, and scalable software systems that solve real-world industrial and everyday challenges.**

I believe great AI engineering requires more than model training in isolated notebooks. It demands clean data pipelines, resilient backend architectures, and thoughtful human-centred interfaces.
